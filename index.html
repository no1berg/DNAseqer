DNAseqer

A lightweight and simple DNA sequence analysis tool written in Python.

Features

  • Lightweight: No heavy dependencies.
  • Simple to Use: Command-line interface for quick analyses.
  • Work in Progress: More features coming soon.

Installation

Clone the repository and run the script:

git clone https://github.com/no1berg/DNAseqer.git
      cd dnaseqer
      python dnaseqer.py
