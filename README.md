# A light weight and simple DNA sequence analysis tool

DNAseqer is a python tool for DNA sequence analysis. It is designed to be lightweight and easy to use, making it suitable for quick analyses without the need for complex installations or configurations.

# Features
- **Lightweight**: No heavy dependencies, runs on any system with Python.
- **Simple to Use**: Easy command-line interface for quick analyses.

# Work in Progress
This project is still under development. Features and functionalities will be added over time.
