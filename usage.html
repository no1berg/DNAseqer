Running DNAseqer

To run the DNAseqer tool, follow these steps:

git clone https://github.com/no1berg/DNAseqer.git
cd dnaseqer
python dnaseqer.py

Input Format

When prompted, enter a DNA sequence using only the characters A, T, C, and G. For example:

ATGCGTACGTAGCTAGCTAGCTAA

Example Output

After entering a valid DNA sequence, the tool will display:

  • DNA sequence length
  • GC content percentage
  • Open Reading Frames (ORFs)
  • Transcribed RNA sequence
  • Translated protein sequences

Example:

Using DNA sequence: ATGCGTACGTAGCTAGCTAGCTAA

----- Sequence Statistics -----
DNA sequence length: 24 nucleotides
GC content: 50.00%

----- Open Reading Frames (ORFs) -----
Open Reading Frames (ORFs) found: ATGCGTACGTAGCTAGCTAGCTAA
Total number of ORFs found: 1
GC content for each ORF: 50.00%

----- Transcription -----
Transcribed RNA sequence: AUGCGUACGUAGCUAGCUAGCUAA
Transcribed RNA from ORFs: AUGCGUACGUAGCUAGCUAGCUAA
Translated protein sequences from ORFs: MRTRYLAL
